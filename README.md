# 🧠 IndicAI — Multilingual Intent Classifier

A lightweight, **multilingual** intent classification system for Indian languages.  
Classifies user messages into 7 intents across **English, Hindi, Telugu, Tamil, and Hinglish**.

---

## 📁 Project Structure

```
indicai/
│
├── train_model.ipynb      ← Training notebook (run in Google Colab)
├── app.py                 ← Streamlit web app
├── intents.json           ← Training dataset (all languages)
├── requirements.txt       ← Python dependencies
├── README.md
│
└── model/
    ├── classifier.pkl     ← Trained LogisticRegression (generated after training)
    └── label_encoder.pkl  ← Intent label encoder (generated after training)
```

> **Note:** `model/` files are generated by running the notebook. The transformer weights (~120 MB) are **not stored** in this repo — they download automatically at runtime.

---

## 🚀 Quickstart

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Train the model

**Option A — Google Colab (recommended):**
1. Upload `intents.json` to Colab
2. Open `train_model.ipynb` in Colab → **Runtime → Run all**
3. Download `model/classifier.pkl` and `model/label_encoder.pkl`
4. Place them in the `model/` folder

**Option B — Local:**
```bash
jupyter notebook train_model.ipynb
```
Run all cells top-to-bottom.

### 3. Run the app

```bash
streamlit run app.py
```

The app will open at `http://localhost:8501`.  
If model files are missing, the app offers a **Train Now** button.

## 🛡️ Invalid Input Handling

The system automatically rejects:

| Input | Why Rejected |
|---|---|
| `@@@@@` | Symbol-only |
| `123456` | Digits-only |
| `aaaaaaa` | Repeated character spam |
| `🙂🙂🙂` | Emoji-only |
| `qwerty` | Latin with no vowels (keyboard smash) |
| `asdasdasd` | Latin with no vowels |

**Returns:**
- `"Unknown / Invalid Input"` — for garbage/spam inputs
- `"Intent not recognized confidently"` — for low-confidence predictions (< 52%)

## ⚙️ Architecture

```
User Input
    │
    ▼
Garbage Detection (regex + heuristics)
    │
    ├── garbage? → "Unknown / Invalid Input"
    │
    ▼
SentenceTransformer("paraphrase-multilingual-MiniLM-L12-v2")
    │   • 12 layers, 384-dim embeddings
    │   • Trained on 50+ languages
    │   • Understands semantic similarity across languages
    ▼
LogisticRegression (multinomial, C=5.0, balanced weights)
    │
    ▼
Confidence + Entropy Check
    │
    ├── confidence < 0.52 OR entropy > 2.10 → "Not recognized confidently"
    │
    ▼
Intent + Confidence Score
```

## 🏫 College Presentation Notes

- **Model**: `paraphrase-multilingual-MiniLM-L12-v2` (HuggingFace, 50+ languages)
- **Why not fine-tuning?** The pre-trained model already understands multilingual semantics. Logistic Regression on top of frozen embeddings achieves >90% accuracy with tiny compute.
- **Why Logistic Regression?** Interpretable, fast, calibrated probabilities, no GPU needed.
- **GitHub size**: < 5 MB (transformer weights download dynamically — not stored).

## 🔧 Threshold Tuning

Edit these constants in `app.py` and `train_model.ipynb`:

```python
CONFIDENCE_THRESHOLD = 0.52   # below → "not recognized confidently"
ENTROPY_THRESHOLD    = 2.10   # above → "not recognized confidently"
```

Lower `CONFIDENCE_THRESHOLD` → more predictions accepted (may reduce precision).  
Higher `CONFIDENCE_THRESHOLD` → stricter filter (may reject valid inputs).
